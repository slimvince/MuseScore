## Background

The current Baroque corpus pipeline works as follows:
  1. `tools/music21_batch.py` reads Bach chorales from **music21's own internal
     corpus** and exports them as MusicXML `.xml` + harmonic analysis `.music21.json`
     into `tools/corpus/`.
  2. `tools/run_bach_preset.py` passes those `.xml` files to `batch_analyze.exe`,
     producing `.ours.json` output in `tools/corpus/`.
  3. `tools/analyze_inversion_errors.py` compares `.ours.json` with `.music21.json`.

This means:
  - batch_analyze reads **music21's version** of the Bach chorales (MusicXML 4.0,
    generated by music21 v9.9.1 + MuseScore 2.1.0), not the DCML MSCX files.
  - music21 is both the score source AND the reference annotator — creating a
    circular dependency on music21's representation.
  - The DCML MSCX files in `tools/dcml/bach_chorales/MS3/` (361 `.mscx` files,
    the authoritative format used for visual inspection in MuseScore Studio) are
    entirely unused in the corpus analysis pipeline.
  - The DCML/WiR human annotations (used as ground truth for three-way genuine
    errors) were written against the DCML MSCX files — NOT against music21's
    representation. Any representation differences cause misalignment.

Goal: migrate the pipeline so batch_analyze reads the DCML MSCX files directly,
eliminating music21's score representation from the equation.

## Step 4 — Assess music21.json regeneration

The `.music21.json` reference files must reflect the same score representation
that batch_analyze analyzes. If we migrate to MSCX, we have two options:

**Option A**: Keep existing `.music21.json` files if measure numbers and region
boundaries are identical between XML and MSCX versions. The music21 harmonic
analysis is still valid as a reference even if the score source changes,
provided the region alignment is preserved.

**Option B**: Regenerate `.music21.json` files from the MSCX files by running
music21 on the MSCX files (music21 can read MSCX). This gives perfect alignment
but requires verifying the regenerated references don't silently change the
three-way genuine error set.

Based on Step 3 results, recommend Option A or Option B and explain why.
