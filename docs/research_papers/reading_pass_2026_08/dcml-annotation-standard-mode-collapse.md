## The key/mode vocabulary, verbatim

- "Major keys are indicated by uppercase, minor keys by lowercase letters." (e.g. `Ab.I` A-flat
  major; `f#.i` F-sharp minor.)
- **The modal collapse, in the standard's own words: "Dorian and phrygian modes are annotated
  as minor keys; lydian and mixolydian as major."** There is no distinct syntax for a modal
  tonality — the key axis of the standard is two-valued (major/minor) by construction.

## Applied and local keys (context for the grading conventions)

Slash notation is relative to the LOCAL key and does not change it (`V65/IV`;
`iio65/vi V7/vi i/vi` for fleeting tonicization); dot notation changes the local key and is
relative to the GLOBAL key (`V.I`). "Slash notation is relative to the local key, whereas the
modulation key is relative to the global key."
