# Score Census — Plain Symbolic Collections (no analytic ground truth)

**Scope:** machine-readable symbolic SCORE collections WITHOUT analytic ground truth (Roman-numeral / functional annotations). Usable as regression material, qualitative review, stress testing, and future annotation targets for the harmonic-analysis project. Any genre, any era. (The GT-annotated half — DCML corpora, ABC/BPS, When-in-Rome, etc. — is the other agent's census.)

**Method:** container enumeration to closure, not keyword sampling. Source classes 1–7 below.

**Date compiled:** 2026-07-02.
**Fact tags:** `[verified]` = source page fetched during this census; `[reported]` = from search snippet / secondary source, not independently fetched. Sizes never fabricated — "?" where unknown.

**License-class shorthand:** PD (public domain), CC0, CC-BY, CC-BY-SA, CC-BY-NC(-SA), ODbL, research-only (custom/academic), mixed, proprietary/grey. Project policy: non-redistributable material is hash-pinned, never committed.

## Residual risk — where more collections could hide

1. **National-library MEI editions**: Danish Centre for Music Editing (Carl Nielsen works in MEI), German library digital editions (SLUB Dresden), Spanish/Italian national projects — individually small, collectively nontrivial; none enumerated here.
2. **The ABC long tail**: FolkWiki (Swedish), JC's ABC Tune Finder, Village Music Project (English), norbeck.nu (Irish/Swedish) — thousands more monophonic tunes; low harmonic-analysis value, so bounded risk.
3. **East-Asian and non-Western symbolic sets** beyond SymbTr/jingju: Essen's Han-Chinese extension (esac-data.org), KOMA/Korean gugak encodings, CompMusic offshoots — likely a few thousand pieces.
4. **Academic one-off corpora attached to papers** (ISMIR/TISMIR dataset tracks each year): e.g., new lead-sheet or tablature sets appear annually; the "awesome MIR datasets" index (github.com/ismir/mir-datasets + mirdata library) is the watch-list container; a periodic re-sweep of mirdata's loader list would catch these mechanically.
5. **Hooktheory-like commercial-with-API sources** (Chordify, Ultimate Guitar tabs, Musicnotes): symbolic-ish, copyright-encumbered, excluded by license class rather than ignorance.
6. **MuseScore.com churn**: PDMX is a 2024 snapshot; the PD population on MuseScore.com keeps growing — re-scrapes (or PDMX v2) may supersede it.
7. **Overlap/dedup risk rather than discovery risk**: KernScores ↔ craigsapp ↔ music21 ↔ MuseData encode the same works repeatedly; GigaMIDI absorbs Lakh/MetaMIDI; any corpus accounting must dedupe by work, not by container.

## Recommendation shortlist for the harmonic-analysis test bed (this census's half)

1. **OpenScore Lieder** — CC0, professionally proofread real engraving, 1,300+ late-romantic/chromatic songs, official mscx→MusicXML pipeline. The single best fit for stressing key/chromaticism beyond the Baroque corpus.
2. **KernScores / craigsapp core classical sets** (Beethoven sonatas, Chopin mazurkas+preludes, Haydn/Mozart/Beethoven quartets, Scarlatti, Joplin) — versioned Git containers, kern→MusicXML trivial, spans galant→late-romantic→ragtime harmony.
3. **OpenScore String Quartets** — CC0, 100+ real quartets, fills the multi-voice texture gap between chorales and piano scores.
4. **PDMX** — scale and stylistic breadth (250k PD MusicXML) for stress/soak testing and future annotation mining; requires quality filtering via its rating metadata.
5. **EWLD (+ OpenEWLD as the committable slice) and the Omnibook MusicXML** — real jazz/pop notation with chord symbols in native MusicXML; EWLD/Omnibook hash-pinned (license-grey), OpenEWLD (502 PD songs) committable. Directly exercises the Jazz preset with genuine lead-sheet harmony.
