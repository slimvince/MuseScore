## Task 1 — the group gloss reads the register's own title

### (a) What is wrong, stated at the object

In `tools/audit/gen_derivation_boot_pack.py`, `candidates()` contains exactly this:

```python
        if e.get("group") in spec["groups"]:
            why.append({"criterion": "group", "matched": e.get("group"),
                        "means": "Layer 2 — the slicer"})
```

The string is hardcoded. **The only criterion that carried a group term before `l2` named exactly
one group, E** — `harmony-boundary`'s `("E",)`, the other two subjects' group terms being empty —
and E's title in the decisions register is that same string. *(Why it was written that way is not
established and is not claimed; what is established is that it was true of every criterion in the
table until this one.)* The `l2` criterion names **six** groups, and for five of them — A, C, D, F
and G — that gloss is **false**.

### (b) The repair, and why it is a repair and not a behaviour change

The decisions register's group titles have one home: the `groups` table of
`tools/audit/decisions/backbone_decisions.json`, a list of `{"id": ..., "title": ...}`. **That this
is the same table `DECISIONS.md` renders its group headings from was checked at the object and not
assumed:** `tools/audit/decisions/gen_decisions_register.py` takes `groups = backbone["groups"]` and
emits each heading as `f"## {g['id']}. {g['title']} — [full entries]({gfile})"`. The boot-pack
generator already reads that same backbone file. **So the gloss reads the title from there rather
than carrying a second copy of it (#6), and the register and this tool cannot drift apart.**

**Group E's title in that table is `Layer 2 — the slicer`, character for character — checked as
characters and not by eye:** a pattern carrying an explicit EM DASH (U+2014) matches once in the
backbone and once in the generator, so the two strings do not differ by a dash. So the
`harmony-boundary` subject — the only built subject whose criterion carries a group term — renders
byte-identically after the repair. **That is the proof this is a repair: `--check` must still exit
0.**

### (c) Insert this helper immediately BEFORE the line `def candidates(` and after the blank lines that follow `haystack()`

```python
_GROUP_TITLES: dict[str, str] | None = None


def group_title(group: str) -> str:
    """The decisions register's OWN title for a register group, read from the table that defines it.

    NOT a second copy of those titles (#6): `DECISIONS.md` renders its group headings from the same
    `groups` table this reads, so the register and this tool cannot drift apart.

    BEFORE 2026-09-05 this gloss was the hardcoded string "Layer 2 — the slicer", written when the
    only criterion carrying a group term named exactly one group, E.  The `l2` criterion names six,
    and for A, C, D, F and G that string is false.  Group E's title in the backbone is that same
    string, so the `harmony-boundary` subject's rendered manifest is byte-unchanged by this repair,
    which is what makes it a repair and not a behaviour change.  The former wording is preserved
    here rather than deleted (#12).

    An unknown group is a STOP rather than a fallback: a gloss that silently degrades to the bare
    letter would read as a title and be believed.
    """
    global _GROUP_TITLES
    if _GROUP_TITLES is None:
        _GROUP_TITLES = {g["id"]: g["title"]
                         for g in read_json(BACKBONE).get("groups", [])
                         if g.get("id") and g.get("title")}
        if not _GROUP_TITLES:
            raise Stop("the backbone carries no usable `groups` table, so no group title can be "
                       "read and the group gloss has no source")
    if group not in _GROUP_TITLES:
        raise Stop(f"register group {group!r} carries no title in the backbone's `groups` table")
    return _GROUP_TITLES[group]
```

REPO = r"C:\s\MS"
HERE = os.path.join(REPO, "tools", "audit")
spec = importlib.util.spec_from_file_location(
    "gen_dbp", os.path.join(HERE, "gen_derivation_boot_pack.py"))
gen = importlib.util.module_from_spec(spec)

fail = []


def check(name, ok, saw):
    if not ok:
        fail.append({"check": name, "saw": saw})
    return {"check": name, "passed": bool(ok), "saw": saw}


sort = gen.read_json(gen.SORT)
bb_data = gen.read_json(gen.BACKBONE)
backbone = {d["id"]: d for d in bb_data.get("decisions", [])}
for r in bb_data.get("retired_entries", {}).get("entries", []):

home_of = {e["id"]: (e.get("home") or "") for e in design_intent}
cands = gen.candidates("l2", design_intent, backbone)


def crits(c):
    return {w["criterion"] for w in c["matched_by"]}


BY_GROUP = {c["id"] for c in cands if "group" in crits(c)}
BY_KEYWORD = {c["id"] for c in cands if "keyword" in crits(c)}
BY_HOME = {c["id"] for c in cands if "home-document" in crits(c)}

G = BY_GROUP
K = BY_KEYWORD - G
H = BY_HOME - G - BY_KEYWORD
ALL = {c["id"] for c in cands}


def ids(s):
    return sorted(s, key=lambda i: int(i.split("-")[1]))


part_of = {}
for i in G:
    part_of[i] = "group"
for i in K:
    part_of[i] = "keyword"
for i in H:
    part_of[i] = "home-document"

# Every candidate must fall in exactly one part. It does today because the criterion's other two
# terms - the ARCHITECTURE.md passages and the named identities - are both EMPTY by ruling. A
# candidate outside the three would be a real finding, so it is caught and named here rather than
# surfacing as a KeyError in the middle of the rendering.
unpartitioned = ids(ALL - set(part_of))


def gkey(g):
    # Sort register-group keys without assuming every entry has one. All 411 sort entries carry a
    # single-letter group today, checked at the artifact; this does not depend on that staying true.
    return (g is None, g or "")


rows = []
for c in cands:
    rows.append({
        "id": c["id"],
        "register_group": c["group"],
        "register_group_title": gen.group_title(c["group"]) if c.get("group") else None,
        "home": home_of.get(c["id"], ""),
        "title": c["title"],
        # The entry's OWN words, carried so that a verdict written later is checkable at the text
        # it was made from rather than at this artifact's account of it.
        "verbatim": c["verbatim"],
        "plain": c["plain"],
        # WHICH TERM FIRST REACHED IT, in the criterion's own order: the group term, then the
        # keyword list on what the group term leaves, then the home-document list on what both
        # leave. This is a partition and not a statement that no other term also reaches it —
        # `matched_by` below carries every term that did.
        "first_reached_by": part_of.get(c["id"]),
        "matched_by": c["matched_by"],
    })

by_group = {}
for c in cands:
    by_group[c["group"]] = by_group.get(c["group"], 0) + 1

by_group_and_part = {}
for c in cands:
    d = by_group_and_part.setdefault(c["group"], {"group": 0, "keyword": 0, "home-document": 0})
    p = part_of.get(c["id"])
    if p:
        d[p] += 1

by_home_of_the_67 = {}
for c in cands:
    if part_of[c["id"]] == "home-document":
        for w in c["matched_by"]:

                by_home_of_the_67[w["matched"]] = by_home_of_the_67.get(w["matched"], 0) + 1

# The preceding batch published the same sixty-seven by home document, derived by a different
# script. Comparing the two is a CHECK and not a transcription (D-431): if they disagree, one of
# them is wrong and this batch stops.
prior = gen.read_json(os.path.join(HERE, "l2_criterion_written_check.json"))
prior_homes = {k: v["count"]
               for k, v in prior.get("the_sixty_seven_by_home_document", {}).items()}

checks = [
    check("the design-intent population is 244", len(design_intent) == 244, len(design_intent)),
    check("the criterion returns 244 candidates", len(cands) == 244, len(cands)),
    check("the group term picks 130", len(G) == 130, len(G)),
    check("the keyword list adds 47", len(K) == 47, len(K)),
    check("the home-document list adds 67", len(H) == 67, len(H)),
    check("the three parts sum to 244", len(G) + len(K) + len(H) == 244,
          len(G) + len(K) + len(H)),
    check("the three parts partition the candidates with none left over", G | K | H == ALL,
          len(ALL - (G | K | H))),
    check("every candidate falls in exactly one of the three parts", not unpartitioned,
          unpartitioned),
    check("the per-register-group counts sum to 244", sum(by_group.values()) == 244,
          sum(by_group.values())),
    check("the published rows are the whole candidate set", len(rows) == 244, len(rows)),
    check("every row carries the entry's own verbatim",
          all(r["verbatim"] for r in rows), sum(1 for r in rows if not r["verbatim"])),
    check("every row carries the entry's own plain restatement",
          all(r["plain"] for r in rows), sum(1 for r in rows if not r["plain"])),
    check("the sixty-seven by home document agree with the preceding batch's artifact",
          by_home_of_the_67 == prior_homes,
          {"here": by_home_of_the_67, "there": prior_homes}),
    # Task 1's repair, checked at the values it produces rather than at the diff.
    check("group_title('E') is the register's own title for group E",
          gen.group_title("E") == "Layer 2 — the slicer", gen.group_title("E")),
    check("every group match is glossed with that group's own register title",
          all(w["means"] == gen.group_title(w["matched"])
              for c in cands for w in c["matched_by"] if w["criterion"] == "group"),

          all(w["matched"] == "E"
              for c in cands for w in c["matched_by"]
              if w["criterion"] == "group" and w["means"] == "Layer 2 — the slicer"), None),
]

        "L2's CANDIDATE LIST, PUBLISHED WHOLE. Every design-intent entry the ruled criterion "

                       "candidates": len(cands)},

            "picked_by_the_group_term": len(G),

            "added_by_the_home_document_list": len(H),
        },

                                       for k in sorted(by_group_and_part, key=gkey)},
        "the_sixty_seven_by_home_document": dict(sorted(by_home_of_the_67.items())),
