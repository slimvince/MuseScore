## 2. The subject, re-explained from scratch

Once a harmonic analysis has decided the music — the tonality at each moment, where each harmony gives way to the
next, which sounding notes belong to the harmony and which decorate it, and what chord is read over each stretch — a
good deal more can be said about it without deciding anything new, and some further things can be said only by
deciding something new. **L3 is the layer that says them.**

The charter's question, in its own words: *given a settled tonal reading, what else does a harmonic analysis of this
music say?* It publishes five things. **The cadence at each phrase end, with its type** — a half cadence, an authentic
cadence, a deceptive close, and so on. **The phrase and section grouping** — where the phrases end, and how phrases
group into larger sections. **The chord symbol** — the chord written as a root, a quality and a bass note, the way a
lead sheet writes it, read off the decided chord. **The figured bass** — the thoroughbass figures, the intervals above
the bass, describing the decided harmony. **The harmonic rhythm** — the pattern in time of the changes of harmony,
read against the meter.

The charter fixes three things about how. The chord symbol is a **view** of the decided chord: its root is the tonic
transposed by the degree's interval, and nothing is settled in computing it. The notated phrase evidence — fermatas,
rests, repeats, double bar lines — is read by the layer beneath, and **which of it marks a phrase end is decided at L3**,
the decisive further evidence being cadential. And **a read-off fact may never revise the decision it was read off**:
nothing L3 publishes reaches back into L2's reading.

**The question this file answers is neither of those.** A session that had not read this project's specifications or
code was asked how L3 should work, and answered in forty-two statements. This file sets that answer beside the
specifications the project already holds, and gives **every statement of those specifications** in the population
exactly one recorded fate. It settles nothing: it tabulates, so that the user can settle it.

## 5. The vocabulary, and that it is CLOSED

Two axes, both closed, both fixed before any placement began. **No other verdict word appears in this file, and no
numeric grade appears anywhere in it.**

**The CURRENT-TEXT AXIS — one per named derived statement, per row.** This axis is evidence about the present text and
is **never a verdict on the derivation**:

- **AGREES** — the derived statement and the outgoing statement say the same thing in substance.
- **DIFFERS** — they say different things. The row then states the difference in one sentence, in both texts' own
  words, **and chooses nothing between them.**
- **THE DERIVATION IS SILENT** — no derived statement speaks to this outgoing statement.

**The DISPOSITION AXIS — exactly one per outgoing statement**, out of the five the phase definition names, plus the
honest default:

- **ADOPTED — carried** — a derived statement already carries this content in substance (named by its L3-S-number).
- **ADOPTED — proposed** — no derived statement carries it; it is not implementation-describing, not another charter's,
  not historical, and the worth test does not discard it. **This is a PROPOSAL to the user that the outgoing content be
  added to the derived specification.** The proposal is written in one sentence beside the row. It is never written
