## Task 3 — the operational procedure (measured + drafted)

### 3.1 The successor sandwich — runnable + timed

New instrument **`tools/robust_stop_diff.py`** (thin orchestration over a8 outputs; constraint-10
total-unification — it re-implements NO scoring/comparison, only diffs the run-identity sets and the
class-split durations the a8 instrument already produces; the robust analogue of `characterise_bir_false.py`).

**The exact check a future increment runs:**
```
# 1. measure the candidate (a8 self-validates grid==oracle on every piece)
python tools/a8_rebaseline_measure.py --out-dir <cand_out> [--corpus-root <scratch_root>]
# 2. diff the candidate vs the committed reference
python tools/robust_stop_diff.py --candidate <cand_out>     # exit 0 iff every preset passes (a)
```

**Pass/fail rule (per preset, root respect, variant (b)):**
- **(a) HARD STOP** — the **class-(b) (pitch-class-decidable-root) root-disagree DURATION must be
  NON-INCREASING** vs the committed reference. Any preset increasing ⟹ FAIL (exit 1).
- **(b) DIAGNOSTIC (mandatory, never fails by itself)** — the **run-level set-diff** vs the reference
  (added/removed `stem@runStartTick` runs, each tagged with its two-tier class) is ALWAYS listed. This is the
  A-8 dual-track's *mandatory explained per-run set-diff* — zero-new-case cannot scale to ~7k runs, so the
  gate is a duration non-increase + an explained diff, not a set-identity.
- **(c) TRACKED** — the **class-(a) (symmetric/share-tone coin-flip) root-disagree duration** delta is reported;
  a large net increase trips **`** INVESTIGATE`** (advisory threshold `CLASS_A_INVESTIGATE_TICKS = 9600`, the
  CLAUDE.md guardrail-(3) "many symmetric sonorities destabilized" carry-over) — not an automatic stop.

**Timed (this corpus, this machine):** step 1 (a8 full-3) **≈6 s** (dispatch predicted ~14 s at Phase-0
timing — faster now); step 2 (diff) **<1 s**. **Total successor sandwich ≈6 s.**

**Demonstrated end-to-end** (not just the trivial identity case):
- *Self-comparison* (candidate = current corpus): empty run set-diff (+0/−0 all presets), all class-durations
  Δ=0, **OVERALL PASS** — and the parse count equals the enumeration line count exactly on all three presets
  (a `parse_runs` guard now **raises** if any non-header line fails to match, so a future format drift or a new
  stem pattern cannot silently shrink the diff base — this caught+fixed a real bug: the hyphen stem
  `bwv248.33-3` was dropping 96 runs from an earlier `bwv[\w.]+` pattern).
- *Perturbed candidate* (synthetic): a +960-tick class-(b) bump ⟹ Baroque **HARD STOP FAIL** with the run
  diagnostic listing the injected +1 added / −2 removed runs by class; a +12000-tick class-(a) bump ⟹ Jazz
  **INVESTIGATE** flag while still PASS on the hard stop; Default clean PASS; **OVERALL FAIL, exit 1.** All
  three code paths proven.

### 3.4 Cost / practicality note (the trade the user ratifies)

| | batch sandwich (incumbent) | robust sandwich (successor) |
|---|---|---|
| **command** | `run_bach_preset.py` regen ×3 + `characterise_bir_false.py` ×3 | `a8_rebaseline_measure.py` (1 run, 3 presets) + `robust_stop_diff.py` |
| **time** | regen is minutes (rebuilds `.ours.json` ×352×3); characterise ~seconds | **≈6 s total** (Python over on-disk `.ours.json`/WiR; no regen if corpus fixed) |
| **artifact size** | 3 × ~52-line identity sets in CLAUDE.md prose | 3 × ~6.9k-run enumerations (~0.5 MB each) + summary + manifest in `tools/robust_stop/` (~1.6 MB) |
| **failure readability** | a set-diff of ~52 named cases — human-legible at a glance | a class-(b) duration Δ (one number/preset, the hard stop) + an explained run set-diff (added/removed, class-tagged) — legible but larger; the ~7k-run scale is why the gate is duration+explained-diff, not zero-new-case |
| **what it measures** | a small music21-filtered residual (undercounts ~15–56×); ≈53% class-(a) coin-flip | the full human-GT per-onset root error, segmentation-invariant; ~96.5% class-(b) functional |

**The trade:** the robust sandwich is **faster** (≈6 s vs a multi-minute regen when the corpus already exists),
**segmentation-invariant**, and governed by the **meaningful** (class-(b) functional) quantity — at the cost of
a **larger committed reference** (~1.6 MB of run enumerations vs 52 lines of CLAUDE.md prose) and a
**duration-plus-explained-diff** failure surface instead of a 52-case name list. The batch stop's at-a-glance
legibility is real; the robust stop's honesty (it doesn't undercount 15–56×) and reuse (one instrument for the
objective and the stop) are the reasons to switch. **The user ratifies this trade at R10-b, eyes open.**
