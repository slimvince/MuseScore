## 3. §3 — the OVERRIDE-DUTY answer (the headline) with identity sets

The Phase-5b question: of the recorded **86 class-(b) decoder cases (61 Commit / 25 Inherit)**, how many does the §5.5
case-4 override correct — and must it extend to Inherit? Measured on THIS (decoder) substrate:

| Preset | L4 decidable-wrong (Commit/Inherit) | **corrected by override** | RESIDUAL (Commit/Inherit) | ⚠ override REGRESSED a correct commit | overrides fired |
|---|---|---|---|---|---|
| Baroque | 2181 (1878/303) | **45 (all Commit)** | 2136 (1833/303) | **720** | 968 |
| Jazz | 2163 (1861/302) | **45 (all Commit)** | 2118 (1816/302) | **707** | 955 |
| Default | 2181 (1878/303) | **45 (all Commit)** | 2136 (1833/303) | **720** | 968 |

**Answer:** the override, at its **default (untuned, precision-phase-seed) thresholds**, is **net-harmful on the decoder
substrate.** It fires ~968× but corrects only **45** decidable-wrong roots while **regressing ~720 correct commits**
(net ≈ **−675** on pitch-class-decidable roots). It corrects **0 Inherit** cases (all 303 Inherit-wrong remain residual).

- **The mechanism is correct** (verified at the score): e.g. `bwv10.7@6240` L4 committed root 0 (C, DCML-correct); the
  override fired (`l5Basis=FineGrainOverride`) and **selected root 9 from the carried alternatives** (`alternatives roots
  = [0,0,0,0,9,0]`, so 9 is a carried reading — never a re-derivation), emitting `iiø7`; DCML says `I`. So the override
  **selects legally but decides wrongly** at default thresholds.
- **Does the override drive the 86 to zero?** No — and it does the opposite net. **The evidence says the override must
  NOT be extended to Inherit as-is** (it would only add more mis-fires); the prerequisite is **precision-phase
  threshold calibration + the D-L5a boundary squash** (so the §8 `S_contra > θ·C_incumbent` comparison is on
  commensurable quantities), NOT a Commit→Inherit broadening. This is the single most consequential E0 finding for engage.
- **Residual identity set (sample; full set reproducible from the committed harness + corpus):** Commit residuals e.g.
  `bwv10.7@34080 (L4=5 DCML=2)`, `bwv101.7@1920 (10→2)`, `bwv102.7@16800 (10→0)`, `bwv103.6@1440 (2→11)`; **Inherit
  residuals** (the "extend-to-Inherit?" set, all uncorrected) e.g. `bwv10.7@38400 (7→0)`, `bwv102.7@21840 (7→0)`,
  `bwv103.6@10560 (9→4)`, `bwv103.6@21840 (6→1)`, `bwv11.6@23280 (11→6)`. Override **regressions** e.g. `bwv10.7@6240
  (0→9)`, `bwv101.7@5760 (5→2)`, `bwv11.6@11760 (9→4)`.
- **Caveat (see §6):** the canonical **86** was measured at a coarser (region/analysis-unit) granularity; my **2181** is
  the per-slice count aligned to DCML regions (granularity-inflated ~7× per the CLAUDE.md per-beat caveat). The
  *direction* (override net-harmful, 0 Inherit corrected) is granularity-robust; the exact 86-set reconciliation is an
  unknown.
