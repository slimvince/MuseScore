## 3. Documentation only. Algorithm: no change.

The method that stands, as put: L2 decides key and chord together and publishes the chord as a degree in its tonality;
L3 publishes facts read off it (chord symbol, figured bass, harmonic rhythm, cadence with type at each phrase end, phrase
and section grouping, key areas, the pivot re-expression); L3 publishes no tonic / subdominant / dominant summary and
writes nothing into the score; the augmented-sixth sub-type is L2's chord kind; a display turns published facts into
text; the code computing L3's facts depends on no type of the score editor. Neither ruling adds a published fact, field,
evidence or check, or decides how the application is built.
