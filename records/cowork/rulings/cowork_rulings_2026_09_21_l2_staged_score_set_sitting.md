## 3. Ruling 3 — the analysis goes in as the SCORE FILE ALONE, with the published table as a named fallback

**Ruled.** Each annotated member is staged as its `.mscx` score file alone. The labels are inside it,
attached to the music. **The published `harmonies` table is NOT staged**, because its derived columns
— the local key at that point, whether the chord is borrowed and from where, the cadence, and the
spelled-out list of notes the label implies — are somebody else's decomposition of the label, which
is close to the thing L2's detail specification is chartered to derive.

**The qualification is part of the ruling (the user's own word).** If the deriving session reports
the score-file form unreadable in practice, **the table is the fallback, with the derived columns
NAMED AND CUT rather than left in under an instruction not to read them.** The cut is written by the
pack-build side and verified at the file before release, on the shape Ruling 5 of 2026-09-05 already
uses for the withheld passages.

*Ground, stated with the ruling:* the alternative needs no do-not-read instruction at all, and a rule
that needs no enforcement is worth more than one that does — measured against the `l0-l1` brief's own
`<Harmony>` instruction, whose only guarantee is the session's own record of what it passed over.

**Declined:** the table beside the score file unconditionally (the columns that make it useful and
the columns that contaminate it are the same file); the table alone.

## 7. ★★ After the withdrawal — the alignment established, and a second and larger finding

### 7.1 The chorale pairing's alignment IS established, at five structural landmarks

§6 left the pairing of the *When in Rome* chorale-011 analysis with the local score
`tools/dcml/bach_chorales/MS3/011 Jesu, nun sei gepreiset.mscx` corroborated but not proved, and
named the bar-by-bar alignment as the thing Ruling 7 of 2026-09-05 requires before staging. **It was
then checked at the score file's own structure, and it holds at every landmark the analysis states:**

- **the anacrusis** — the analysis opens `m0 b4 C: I`, a 4/4 bar entered on beat 4; the score's first
  measure carries `len="1/4"`;
- **the repeat** — the analysis reads `m8 I :|| b4 V`; the score's **ninth** measure carries
  `<endRepeat>2</endRepeat>` and `len="3/4"`, which is the truncation that `b4 V` outside the repeat
  implies;
- **the change to 3/4** — the analysis states it before `m13`; the score's **fourteenth** measure is
  the one carrying `<sigN>3</sigN>`;
- **the return to 4/4** — the analysis states it before `m29`; the score's **thirtieth** measure is
  the one carrying the third time-signature statement and `len="4/4"`;
- **the extent** — 66 measure elements across two staves is **33 measures**, and the analysis runs
  m0 through m32, which is 33.

**Counting the anacrusis as m0, every one of those lands on exactly the measure the analysis names.**
**What is still NOT explained:** the two sources give different Riemenschneider numbers — the
analysis's `remote.json` reads 11, the score's own text reads *"(BWV 41/6 ohne Instrumentalpart;
R 204)"*. Both name BWV 41/6 and the five landmarks agree, so the discrepancy bears on neither
identity nor alignment; **it is recorded unexplained rather than reasoned away.**
