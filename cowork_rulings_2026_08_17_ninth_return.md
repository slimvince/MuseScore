## 1. Ruling 1 — the evidence pin is ratified AS A CLASS, not for one script (Alternative A)

**A GENERATED DOCUMENT PUT TO THE USER FOR A RULING JOINS THE PINNED KIND AT THE MOMENT IT IS RULED
FROM: its generator thereafter reads its inputs at the git objects of the commit the ruling names.**

This ratifies what the ninth batch did — `gen_claude_md_finer_surface.py`'s span data file pinned to
`cfb69a7ecb`, the commit `cowork_rulings_2026_08_17_seventh_return.md` names as where the surface
was ruled — and it rules the class the act belonged to, which CC correctly declined to rule for
itself. **It EXTENDS Ruling 1 of §6 of `cowork_rulings_2026_08_16_preparation_return.md`**, the
Kind-1 treatment, from the two completed measurements that treatment named to every generated
document a ruling was taken from.

**THE GENERAL FORM, which is the reason the class is ruled rather than the instance (CC's F54):
a document generated from a live data file is not evidence of what was PUT in front of the user
unless its generation is PINNED.** Without the pin, an ordered change to a classifying rule silently
rewrites the proposal the user actually ruled on — which is exactly what the ninth batch measured
before deciding, and did not do.

**THE GROUND.** The exposure is not one script's: at least three other generated ratification
documents in the tree carry it today — the residue document, the rulings-sort document and the
governing-surface split document — and the rulings-sort document's banner had already to be
corrected by hand at the eighth batch for a closely related reason. #12 is the principle at stake
directly: the evidence of what was put is what #12 exists to preserve, and #19 adds that a ruling
read back from a rewritten document is trust in something never established. Ruling the class costs
one clause and answers all of them; ruling the instance guarantees the question returns.

**WHAT THE PIN DOES NOT FREEZE, stated so the F22 cost is not thought to be repeated.** A
ratification document's job ends at the ruling. Pinning it afterwards removes nothing live — the
current classification stays available in the underlying data file, which is NOT pinned and
continues to re-derive. The frozen-file cost the user accepted at F22 was accepted for a population
that FEEDS a live derivation; this one feeds nothing.

**WHAT THIS RULING DOES NOT DO.** It moves no verdict, no fate and no population. It does not run
`gen_claude_md_finer_archive.py --apply`, which stays unrun. It touches no `CLAUDE.md` span — both
spans ruled at the eighth-return sitting stay at site and that question is CLOSED. A later ruling
can unpin any member in one edit; nothing here is irreversible.
