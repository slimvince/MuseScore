## Why it is worth a row and not a silent fix

Two reasons, neither of them tidiness. First, the banner is an **instruction to a future session** —
it tells whoever opens the file not to commit it, which is a standing rule of the "Held for Cowork"
kind, and a stale standing rule is worse than none. Second, the same document's own §1/§2.1/§5
disagreement about the piece-start shortcut ([[OI-315]]) shows this file was left in the state its
banner describes and then overtaken; the banner is the marker that would have told a reader so, and
it says the opposite.
