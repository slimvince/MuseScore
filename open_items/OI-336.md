## What moves

[[OI-332]] classifies itself an APPARATUS row, and states its ground in its own words:

> Two of the three are pointers and a banner — the line the non-gating declaration draws explicitly
> names *a pointer, an anchor, a label, a banner* as apparatus.

That reads one half of `CLAUDE.md`'s non-gating declaration. **The same sentence continues:**

> a correction to a statement about the analysis **or its build state**, or the completion of a
> specification, GATES

`cowork_layer1_extend_design.md` carries a banner reading *"Read-only design — no code"* over two
operations that are **built** — `NoteModel::build` and `NoteModel::extend`, verified at the header by
[[OI-332]] itself. **A banner asserting that a design has no code, over code that exists, is a
statement about the build state.** So D-438's own line reaches it, in the clause the row did not
quote. `docs/stage4c_cadence_key_design.md` — a design whose approach the record FALSIFIED
(**D-290**) with no note saying so — is a statement about the analysis, and reaches the same clause.
`cowork_layer3_reachback_design.md` (a drifted code anchor) does not, and stays apparatus on both
tests at once.

## Why this row exists rather than a correction

**The non-gating verdict set is DERIVED, never hand-listed.** `CLAUDE.md` says so in terms — the set
is generated by `tools/audit/gen_nongating_apparatus_rows.py`, which parses the INDEX itself, and
[[OI-319]]'s own provenance records the reason a verdict is not hand-added: *"a hand-added verdict for
a row the cut never reached is exactly the hand-listing `CLAUDE.md` forbids."* Moving this one means
changing that tool's authored verdict table and a published classification, which is a ruling.

## The two tests do not conflict — they have different subjects

Stated so the next session does not read this as a contradiction. **R1 (D-639) decides what PHASE 1
OWES**: whether a document's account of itself must be corrected before the completion statement.
**D-438 decides what a STAGE WAITS ON.** A row can be inside phase 1's doc-sync half and still gate
nothing, or gate while sitting outside it. Here they happen to agree on all three documents once both
halves of each test are read, which is corroboration rather than coincidence: both draw their line at
whether a reader would be misled about the system.

## What is NOT in doubt

No analysis behaviour, no measurement and no register entry rests on any of it. [[OI-332]]'s three
