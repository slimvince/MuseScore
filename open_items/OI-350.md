# OI-350 — Route (i) cannot complete in the generated artifacts while the classifier's apply is held: a newly written delegation lands its entries in class C and STOPS four generators, because the finish-line machinery reads a stored field only the apply writes

> STATUS IS AUTHORITATIVE IN THE INDEX (OPEN_ITEMS.md) — this file carries narrative and provenance only and is NEVER the status of record

**Section D — instrument / measurement layer (the decisions register's own classification
machinery). Found 2026-08-08 (CC, `cc_instruction_document_routes_and_d472.md`, Task 4) by
regenerating everything that follows the register, which is what that task orders.**

## What happened

The user's document-route ruling of 2026-08-08, route (i), had three delegations written into
`ARCHITECTURE.md` for `cowork_joint_estimator_factorization.md`,
`cowork_notation_adoption_increment.md` and `docs/llm_integration.md`. Each was graded in
`gen_phase1p_delegation_bar.FORMS` as an explicit delegation clause, and each document's
`section_home_criterion` block was given `delegation_scope: "document"` with a per-section kind
judgment for every section holding an entry — the authored inputs those tools refuse to run without.

**The derivation then behaves exactly as the ruling intended, and it is visible:**
`gen_home_classification.py --check` re-derives the eleven entries of those three documents as
**contract-home**, per document and by identity. That is the DERIVED movement assumption A3 asks
for, and it is not hand-assigned.

**But every artifact downstream of the register reads a different thing.**
`gen_outstanding_delegations.classify_entry` decides an entry's class from two sources — the LIVE
`FORMS` grade, and the entry's STORED `home_section.delegated` field. The stored field is written by
**one writer only: `gen_home_classification.py` in APPLY mode**, which is held un-run by
[[OI-305]] / [[OI-319]]. So the entries now pass the form half and fail the section half on a field
that has never been written, and they land in **class C — "the admitting delegation does not name
this section"** — which is false of them: the delegation names the DOCUMENT and therefore reaches
every section.

Class C carries an authored-draft obligation, so the tool STOPs:

> `STOP: class-C document(s) with no authored draft: [the three]`

**Four generators fail on that one cause**, each importing the one before it (#6):
`gen_outstanding_delegations.py`, `gen_finish_line_item1_routes.py`,
`gen_item1_rehome_blocker.py`, `gen_phase1_completion_inventory.py` and
`gen_phase1_finish_line.py`.

## Why nothing was authored to make it pass

Two available acts were both declined, and the reason is the same for each: both would record
something the record does not say.

1. **Adding a CLASS_C_DRAFT entry for each** would put a *draft delegation for the user to write or
   reject* against three documents whose delegation the user HAS ruled and this session HAS written.
   The field would then assert that a written delegation is outstanding.
2. **Adding them to `SETTLED_BY_A_WRITTEN_DELEGATION`** is the semantically correct list, and its
   own STOP fires immediately for the true reason — *"recorded as settled by a written delegation
   [but] still losing entries to the delegation half — the widening did not take"*. That guard is
   working; it is naming this defect, not a defect in the entries.

**Running the apply was also declined**, on [[OI-305]]'s own recorded reasoning: it would rewrite
`phase1q_reclassification.json` from today's inputs and destroy the record of what phase 1q found —
the [[OI-301]] hazard that row exists to respect. A working session has no licence to resolve a rowed
finding by regenerating over it.

## The general shape, which is why this is a row and not a note

**A classification with two sources of truth — one live, one stored behind a held writer — reports a
false class for anything that moves while the writer is held.** Route (i) is the user's own act
under rule (g), so this will recur for every delegation the user writes until [[OI-305]] is ruled:
the delegation lands, the bar admits it, and the finish line reports the document as *newly broken*
rather than *closed*.
