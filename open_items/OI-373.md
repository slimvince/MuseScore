did not cover."* The run prints `STOP: derived candidate(s) with no authored invocation:
['tools/audit/gen_status_archive_pass.py']` and exits non-zero **whatever every member of the set
said**.

already carries it** at `the_population.unclassified_candidates`, so the condition is not hidden;
