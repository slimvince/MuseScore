# OI-325 — D-501 conformance is unchecked at HEAD: does anything read a written chord symbol as input that influences what the analyzer computes?

> STATUS IS AUTHORITATIVE IN THE INDEX (OPEN_ITEMS.md) — this file carries narrative and provenance only and is NEVER the status of record

**Rowed 2026-08-04 (CC, READ WAVE 3, dispatch `cc_instruction_reads_3.md` Task 5, on the user's
ruling R5), at the ratification of D-501.**

## The decision, and why its conformance needs a row of its own

**D-501** registers the user's operating principle, quoted verbatim at the head of
`docs/symbol_input_audit.md`:

> *Symbols are instructions written by the user, not analysis results. Production paths must not read
> them as input to analysis. Tools may read them only as comparison/ground-truth labels — never as
> input that influences what the analyzer computes.*

The register records **what was decided**; whether the code obeys it is tracked here, as an ordinary
open-items row pointing back at the decision. That split is `DECISIONS.md`'s own rule, and this row
is the other half of it for D-501.

## What is already known, and precisely why it does not answer the question

Three things bear on it, and none of them closes it:

1. **D-066** and **D-305** carry the PRODUCTION ban. They are the same prohibition on the other side
   of the seam; they are decisions, not conformance findings.
2. **D-067** records the category-C resolution of the symbol-input audit — the tool-side symbol paths
   were deleted at `69716deead`.
3. **[[OI-322]]** established at HEAD, by searching every `.cpp`/`.h` in the tree, that
   `analyzeScoreJazz`, `inject-written-root`, `injectWrittenRootTone`, `jazzMode` and
   `scoreHasValidChordSymbols` return **no match**.

Item 3 is real evidence and it is the reason this row is not urgent. But it is an audit **of the
sites one 2026-era audit enumerated, at the five names it happened to use**. It is not a sweep of the
question. In particular, D-501's TOOL clause — a symbol may be read as a comparison or ground-truth
label, and may not be read as input — has never been checked **as a class**: the distinction is
between two uses of the same read, so a name-based search cannot decide it, and the audit that found
the original violations found them by reading code paths, not by grepping.

## Why this gates rather than joining the apparatus rows

**D-438**'s test: *does the row's subject bear on the analysis, its inputs, or an instrument a
measurement depends on? IF YES IT GATES.* The subject here is the analysis's **inputs** — the
strongest form the test has — so it gates, and the non-gating apparatus declaration does not reach
it.

The cost of the defect is why the test lands where it does, and it is stated in D-501's own defense:
a symbol read as input makes the analysis agree with the user rather than with the music; and inside
a measurement tool the same read destroys the measurement outright, because the tool is then
comparing the annotation with itself. The second is a #19/#20 defect — a number that cannot be
established because its instrument is contaminated — not a matter of tidiness.

## Rowed, not run — and what the check owes when it runs

The dispatch says in terms: row it, do not run it. The reason is the sequencing, not the freeze.
**D-231**'s phase 2 requires each search to report its **detection power**, and the phase-2 clause
in `CLAUDE.md` requires every channel enumerated and every miss rate measured. A check run here, on
the side of a read wave, would enter the coverage claim without any of that and would make the
eventual bounded trust statement weaker than if it had never been run.

What it owes when it is run, so that whoever runs it does not have to re-derive the shape:

- **A stated search space** — production `src/` (the notation seams and the composing module) and
  every tool that opens a score, not only the tools the earlier audit visited.
- **A stated criterion** for *"influences what the analyzer computes"* that separates an input from a
  label. Reading a symbol to print it, to compare against it, or to grade with it is admitted; any
  read whose value can change a candidate, a score, a boundary or a key is not. The criterion has to
  be written before the sweep, because it is the thing the sweep is measuring against.
- **Its own miss rate**, on the phase-2 standard.

## What this row does NOT claim

It does not allege a violation. Nothing found in read wave 3 suggests one; the row exists because the
question has not been asked as a class since the decision was registered, and #19's standing rule is
that a thing is trusted after being positively established, never because it is merely unfalsified.
