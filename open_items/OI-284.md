## The finding — three statements, one cause

The document opens by declaring itself "**the single tracker** ensuring every review conclusion is
addressed" (`:5-6`), which is what makes its staleness worth a row: it is where a planner goes to
find out what is done and what is next.

**(1) The current-state layer table (`:42-52`) is false at HEAD.** It records `L4 — chord
(per-slice decoder)` and `L5 — function` as "✅ Built + **DORMANT** … not wired", and states above
it (`:39-40`) that "Every analysis layer is **built dormant and validated byte-identically against
the frozen references** … the production switch ('engage') is **deferred indefinitely**." At HEAD
the joint estimator is the production inference layer on the batch and corpus surface since
2026-07-26 (**D-005**) and on the notation surface since 2026-07-27 (**D-010**); `CLAUDE.md`'s gate
block (A) states the migration is CLOSED on both surfaces and the legacy path is dormant, awaiting
deletion.

**(2) The engage criteria and staged plan (`:122-137`) describe a route that was not taken.** They
are genuinely ratified (user, 2026-07-02) and are entered this wave as **D-417**, so the row is not
about their authority. It is that the switch which actually happened went by a different arc — the
OI-178 adoption and the notation switch — and not through this document's E1→E5 staging; and that
gate **G1** requires "**L6 built dormant**", a layer that was never built and is prohibited from
being built until the bounded-context contract is coded and regression-tested (**D-266**). The
record contains **no ruling that supersedes these criteria**, so the register entry carries the

re-baselined in the same block to "gate Baroque 53 / Jazz 24 / Default 53" with "Authoritative
identity sets: CLAUDE.md gate section". That gate was re-baselined again to 52/24/52 on 2026-07-05
and **superseded in whole at R10-b on 2026-07-06** by the granularity-robust unit (**D-115**);
`CLAUDE.md` block (C) now retains it as "historical reference only". This is the third instance of
the shape [[OI-276]] found in `cowork_voiceleading_axis_design.md`: not a stale description but a
stale **acceptance criterion**, which a future build would try to satisfy.
