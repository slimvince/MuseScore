## 2026-08-08 (CC, `cc_instruction_away_execution.md` Task 1) — the cause established, the other candidate refuted, and the hole wider than this row supposed

**THE CAUSE: THE DRIVE LETTER'S CASE.** `outside_repo` decided whether a token was inside the
working tree with `os.path.commonpath([os.path.abspath(t), ROOT]) != ROOT` — a **case-sensitive
string comparison** on a platform whose paths are case-insensitive. `ntpath.commonpath` takes the
drive from the token AS WRITTEN, so a path spelled `c:/s/MS/…` produced `c:\s\MS`, which is not the
string `C:\s\MS`, and the function answered OUTSIDE for a path plainly inside. The observed command
used a lowercase drive letter. The fix is `os.path.normcase` on both sides: on Windows it
lowercases and squares the separators, and on POSIX it is the identity, so nothing moves on a
case-sensitive platform.

**★ IT IS NOT AN `ls` DEFECT, AND THAT IS THE PART OF THIS THAT MATTERS MOST.** The corpus now
carries `cat` and `grep` — the guard's oldest and most central vocabulary — aimed at repository
files in the same spelling, and at the unwidened guard **both are admitted**. This row's title
names `ls` because `ls` is what was observed. **Every** repository path written with a lowercase
drive letter was admitted, in every utility and both dialects, for as long as the comparison stood.

**THE SECOND CANDIDATE — the gap between the live hook and `decide()` — IS REFUTED, by observation
rather than by argument.** The two agree on both live decisions the record holds: the `ls` this row
records as ADMITTED is admitted by `decide()` on the same string, and the `ls -la /c/s/MS/…` the
away batch issued as its own first command was DENIED by the live hook and is denied by `decide()`
on the same string. **No new forbidden command was issued to test this.** Performing the violation
in order to measure the guard is not a measurement anyone may take, and the record already held
both observations.

**The order was the ruling's, and this row is why it mattered.** Ruling 3 of
`cowork_rulings_2026_08_08_pre_away.md` folds this row into the one family design and requires the
observed command and its path-form variants into the establishment corpus FIRST. They went in
first, with the same spellings aimed outside the tree as controls, and the blindness was measured
before one line of the mechanism moved. Had the fix gone first, the corpus that could not see the
defect would have re-established a guard that had just been repaired — the error the OI-343 and
OI-345 rulings both exist against.
