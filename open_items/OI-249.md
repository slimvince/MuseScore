`jointfactadapter.cpp:163-184`: the measure grid is reconstructed from the first bar's nominal
length, with exactly one irregularity handled — a leading pickup. A mid-score meter change, a
cadenza bar, or any bar whose actual length differs from its nominal shifts every subsequent
grid position, permanently — acknowledged in the code only as a "pathological xml" case
(`:126-129`), which mid-score meter changes are not. Downstream of the drift: the beat-strength
covariate ([[OI-248]]), the bar assignment that decides anacrusis deletion (the [[OI-228]]-family
dated note on pickup events), and the fermata/boundary alignment. The grid question and the
arithmetic question ([[OI-248]]) are one design surface: what metrical facts the adapter derives,
from what, specified where the family design records the input surface. Not fixed here.
