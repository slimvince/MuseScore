# OI-287 — The ratification surfaces and the dispatches have no directory of their own, and moving them re-aims cited paths

> STATUS IS AUTHORITATIVE IN THE INDEX (OPEN_ITEMS.md) — this file carries narrative and provenance only and is NEVER the status of record

**Section F — doc-sync debt (#10) / repository organization. Rowed 2026-08-03 at phase 1l on the
user's ruling of the same date ([[OI-285]] option (a) plus a directory convention), which resolved
the commit half and left the filing half as its own act.**

## What the user ruled, and what this row carries

The ruling on [[OI-285]] had two parts: **commit the ratification surfaces**, and **give the class a
directory**. The first is executed at phase 1l — all seven `cowork_decisions_pending_ratification_*`
files plus the phase-1k dispatch are committed **in place**, at the paths they already had. The
second is rowed rather than executed, and this row says why.

## Why the move is its own act

**Nine committed register entries already cite these paths as the provenance of a ratified
decision.** D-406…D-414 each record their ratification as "the phase-1j queue presented at
`cowork_pending_ratifications_next_session.md` §2", and that document in turn names
`cowork_decisions_pending_ratification_8.md`. Moving a file re-points every citation of it. That is
not a filing decision — it is an edit to provenance fields the user has ratified, which is exactly
the class of change [[OI-285]] itself said a session must not make on its own judgment.

**And the citations are not confined to the register.** The same filenames appear in `STATUS.md`
entries, in the dated notes on several open items, and in each phase dispatch. A rename that fixes
the register and leaves the rest dangling is worse than no rename.

## The constraint any move must satisfy

**Every citation is re-aimed PER CITATION, from the drift report's own output — never by an assumed
path rewrite.** `gen_cluster_dispositions.py --verify` reports each unresolved reference
individually, and that report is the input to the correction, one line at a time. This is the same
discipline the phase-1i/1j/1k waves used for line-number drift, where an assumed uniform shift would
have silently mis-aimed anchors that had not moved by the same amount. A path rewrite has the same
failure mode with none of the visibility: a `sed`-style sweep produces a tree in which every
reference resolves and some of them resolve to the wrong thing.

A move therefore owes, in one act: the new directory named and its membership rule stated (which
classes of document belong — the ratification surfaces, the dispatches, both, or something
narrower); the files moved; every citation re-aimed from the verify report; the three guards run at
the committed tree; and the register's provenance fields re-read to confirm each now resolves to the
file it means.

## What is NOT in doubt

That the files are now committed and therefore durable — the exposure [[OI-285]] found is closed.
This row is about where they live, not about whether they survive.

## Disposition

For the user or for Cowork, not a session: name the directory and its membership rule, then the move
runs as one commit with the per-citation re-aim above. Until then the files stay where they are, and
every citation resolves.
