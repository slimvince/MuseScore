# OI-237 — Sixteen load-bearing decisions have no layer-specification home, so a reader of the layer specifications cannot find them

> STATUS IS AUTHORITATIVE IN THE INDEX (OPEN_ITEMS.md) — this file carries narrative and provenance only and is NEVER the status of record

**Section F — docs / process. Found by the [[OI-207]] adjudication, 2026-08-01. This is the
documentation-gap class [[OI-208]] ruling 2 created.**

## The rule this measures against

`open_items/OI-208.md:55-57`, user-ratified 2026-07-28, verbatim:

> **A decision belongs, wherever possible, in the OWNING LAYER'S SPECIFICATION** — that layer's
>    section of `ARCHITECTURE.md` — and the register is the **index and pointer**, never a
>    substitute home.

and its stated consequence (`:59-61`):

> a decision whose proper home is a layer
>    specification and which is not recorded there is a **documentation gap → an `OPEN_ITEMS.md`
>    row**

## The sixteen

Of the 115 decisions enumerated in `DECISIONS.md`, **16** are recorded outside any layer
specification. They fall into three kinds, and only the first kind is a genuine gap.

**Kind 1 — decisions that govern a layer's behaviour, recorded only in a governing or process
document (7).** These are the gap:

| Register entry | The decision | Where it actually lives | Which layer it governs |
|---|---|---|---|
| **D-032** | Every confidence crossing a layer boundary is [0,1], class-declared, decision-named | `cowork_confidence_contract.md:39-40` | every decision layer's output surface — and it is departed from on the production notation path ([[OI-231]]) |
| **D-096** | Factor forms come from theory; values are fit ONCE against ground truth, never per-case tuned | `OPEN_ITEMS.md:25` | the joint estimator's whole factor set |
| **D-097** | Held-out evaluation and a capacity budget are declared before any fit | `OPEN_ITEMS.md:123` (OI-176/OI-177) | the joint estimator's fit event |
| **D-098** | The exact-decode reserve — the specified prune was never adopted, and what the decoder actually prunes has no specified form | `OPEN_ITEMS.md:197` (OI-188) | the joint decoder's search |
| **D-099** | Negative evidence is information — a ruled-out reading is carried at low confidence, not dropped | `CLAUDE.md` #12 | every layer's output surface |
| **D-100** | Every derived fact is published exactly once on the producing layer's surface; consumers read, never re-derive | `CLAUDE.md` fact-publication corollary | every layer boundary |
| **D-114** | The decoder always commits a key; there is no abstention on the key axis | `CLAUDE.md` gate block (A) | the joint decoder's output — and it sits in tension with D-090 (calibrated abstention), which IS in a layer specification |

Each of these is a statement about **how a layer must behave**, and none of them is discoverable by
reading that layer's section. D-100 is the sharpest case: it is the rule that decides what every
layer publishes, it was created *because* facts were being siloed
(`cowork_siloed_facts_audit.md`, 17 findings), and the specification of every layer it governs is
silent on it.

**Kind 2 — project-wide conventions with no single owning layer (5).** D-076 (score inspection
before diagnosis), D-107 (American English), D-108 (cross-platform), D-112 (never work from memory),
D-113 (music-theory words reserved). `CLAUDE.md` is their correct home; recording them again in a
layer specification would violate D-092 ("a cross-cutting contract is stated once … and never
redefined in a layer doc"). **Not a gap** — listed so the count reconciles.

**Kind 3 — decisions about the tracking machinery itself (4).** D-109 (the open-items register),
D-110 and D-111 (the decisions register's shape), D-115 (the regression stop). These govern process,
not a layer. `OPEN_ITEMS.md` / `open_items/OI-208.md` / `CLAUDE.md` gate block (A) are their correct
homes. **Not a gap.**

## Disposition

Seven specification entries owed, one per Kind-1 decision, each written into the section of the layer
it governs and each pointing back at the document that ratified it. **Writing a specification entry
is a separate, ratified act** ([[OI-208]] ruling 2), so none was written here and `ARCHITECTURE.md`
was not touched by the adjudication.

Two of the seven should be sequenced ahead of the rest because a live question turns on them:
**D-032** is the decision [[OI-231]] records a departure from, and **D-098** is the decision
[[OI-226]] / [[OI-215]] / [[OI-227]] turn on (the decoder's admission rule has no specified form
anywhere).
