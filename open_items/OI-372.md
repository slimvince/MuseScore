# OI-372 — The filing-convention application STOPs before it classifies anything: its authored verdict table names a document its own derivation no longer carries, and the tool has no retired block to move that verdict into

**Section D — instrument / measurement layer. Rowed 2026-08-12 (CC,
`cc_instruction_resume_lapse_records.md` Task 1), on the user's Ruling 67, which released the halt
the previous batch declared over this same tool and directed that the defect be rowed.**

## How it was found, and where its cause was already established

**Not by this session.** The condition was established one batch earlier and is recorded twice in
`cowork_away_returns.md`: §1.21 named the guard, gave the diagnosis in its own words — *"The four
historical banners changed the archive's own overtaking signature"* — and classified the remedy as
*"ordinary **D-648** maintenance … separable from the block"*; §1.22 then re-established the same
thing INDEPENDENTLY at the object and declared the STOP that halted that batch.

**What this session added is the rowing, and it verified the state at the objects first** rather
than carrying it from either record. `python tools/audit/gen_filing_convention_application.py
--check` exits 1 with STOP 3, and `--derive-only` — the tool's own read-only mode — lists the
candidate set the derivation currently carries, which does not include the document the authored
table names.

## What is established, at which object

**The STOP itself.** The tool's third STOP fires: *"authored verdicts for documents the derivation
does not carry: STATUS_ARCHIVE.md -- the tree has moved under the table."* Because it is raised
before anything is written, **the tool produces nothing at all** — the candidate population, the
per-candidate verdicts and the soundness verdict against its seeds are all unavailable while it
stands, not merely one row of them.

**Why the derivation no longer carries the document, read at the tool.** Its S1 signature scans a
document's last non-blank lines for a line carrying BOTH a fate word and a status-or-commit marker.
The window is a fixed count of lines, authored in the tool. The document in question is long and
its tail now carries an ordinary dated entry, so no line inside the window matches, and it is no
longer a derived candidate — while its authored `CONFORMANT` verdict still names it. **Nothing
about the bearing cut touches that derivation**, which is what the user's Ruling 67 turns on.

**Why it is a row rather than an act, and this is the half that is this session's own reading.**
The remedy #12 asks for is to move the verdict out WHOLE, with the reason it left — and **this tool
has nowhere to move it to.** Its two sibling tools each carry a retired block for exactly this case:
`gen_nongating_apparatus_rows.py` has `RETIRED_VERDICTS` and `gen_gating_row_sizing.py` has
`RETIRED_SIZINGS`, both with the same recorded ground — a verdict whose subject left the population
is preserved rather than deleted. This tool has no such block, so discharging the row means ADDING
one, which is a change to a mechanism's structure and **D-436** reserves it.

## What is NOT claimed

**No gating verdict.** Whether this row gates is derived from a cut and is never hand-added — the
lesson [[OI-336]] records and the change **D-436** reserves. No verdict is proposed here, and none
is implied by the section this row is filed under.

**Nothing about the convention.** The user's Ruling 62 of 2026-08-11 and its filing rule, homed at
`cowork_design_doc_template.md`, are not in question and are not restated here (#6). What is broken
is one tool's ability to run, not the rule it applies.

**No other verdict is disturbed.** The remaining authored verdicts in that table are untouched by
this row; it says nothing about whether any of them is right.

**Nothing about the analysis.** No behaviour, no measured value, no golden, no corpus of scores,
nothing under `tools/robust_stop/`. The subject is one documentation-filing derivation, which no
measurement of the analysis reads.

## The closing acts, neither of them this session's

**(a) A retired block, and the verdict moved into it whole** with the reason it left — the shape
both sibling tools already use, so the act has a model and needs no design. It is the act
`cowork_away_returns.md` §1.22 names in one line as what would clear the guard.

**(b) Or a ruling on the signature itself.** The window is a fixed line count, so a document's
being long enough is sufficient to remove it from the population whatever its banner says. Widening
or re-aiming it is a change to a derivation's reach, which **D-436** reserves and which would
silently change what every other candidate's absence means — the reason §1.22 gives for not
touching it under pressure.
