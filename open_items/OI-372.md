## What is established, at which object

**The STOP itself.** The tool's third STOP fires: *"authored verdicts for documents the derivation
does not carry: STATUS_ARCHIVE.md -- the tree has moved under the table."* Because it is raised
before anything is written, **the tool produces nothing at all** — the candidate population, the
per-candidate verdicts and the soundness verdict against its seeds are all unavailable while it
stands, not merely one row of them.

**Why the derivation no longer carries the document, read at the tool.** Its S1 signature scans a
document's last non-blank lines for a line carrying BOTH a fate word and a status-or-commit marker.
The window is a fixed count of lines, authored in the tool. The document in question is long and
its tail now carries an ordinary dated entry, so no line inside the window matches, and it is no
longer a derived candidate — while its authored `CONFORMANT` verdict still names it. **Nothing
about the bearing cut touches that derivation**, which is what the user's Ruling 67 turns on.

**Why it is a row rather than an act, and this is the half that is this session's own reading.**
The remedy #12 asks for is to move the verdict out WHOLE, with the reason it left — and **this tool
has nowhere to move it to.** Its two sibling tools each carry a retired block for exactly this case:
`gen_nongating_apparatus_rows.py` has `RETIRED_VERDICTS` and `gen_gating_row_sizing.py` has
`RETIRED_SIZINGS`, both with the same recorded ground — a verdict whose subject left the population
is preserved rather than deleted. This tool has no such block, so discharging the row means ADDING
one, which is a change to a mechanism's structure and **D-436** reserves it.
