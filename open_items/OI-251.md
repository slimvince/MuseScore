# OI-251 — A two-note tremolo is analyzed as two sequential half-length chords, not one sustained sonority

> STATUS IS AUTHORITATIVE IN THE INDEX (OPEN_ITEMS.md) — this file carries narrative and provenance only and is NEVER the status of record

**Section D — joint module + Layer 1 / feature handling (low; unexercised by the fit corpus).**

A two-note tremolo halves each written chord's duration type (`chord.cpp:540-571`), and no
analysis-side code recognizes tremolo (grep: zero hits under `src/composing`), so a tremolo
spelling one sustained dyad/sonority is read as two consecutive shorter events — splitting one
sonority, with different bass picks possible per half. Musically the tremolo IS one sustained
sound. Orchestral and romantic keyboard textures use it constantly; chorales never do. A
feature-handling rule for the input surface (the [[OI-239]] documentation act's scope), decided
at its #8-correct stage. Not fixed here.
